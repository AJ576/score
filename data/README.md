# Mock data

`mock_stocks.json` is generated by `scripts/gen_mock_data.py` using a
Geometric Brownian Motion model with a fixed seed (42), so regeneration is
deterministic. To rebuild it:

```bash
python scripts/gen_mock_data.py
```

## Schema

```jsonc
{
  "metadata": {
    "generated_at": "2026-05-07T...Z",
    "frequency":    "daily",
    "n_periods":    504,
    "tickers":      ["AAPL", "GOOGL", "MSFT", "AMZN", "TSLA"],
    "seed":         42,
    "start_date":   "2024-05-07",
    "model":        "GBM"
  },
  "data": {
    "AAPL": [
      {
        "date":   "2024-05-07",
        "open":   175.0,
        "high":   178.5,
        "low":    174.0,
        "close":  177.2,
        "volume": 12345678
      },
      // ... one bar per trading day
    ],
    "GOOGL": [...],
    "MSFT":  [...],
    "AMZN":  [...],
    "TSLA":  [...]
  }
}
```

Bars are in chronological order and span ~ two trading years (504 Mon–Fri
days starting at `start_date`). All dollar fields are rounded to 4
decimals; volume is an integer.

## Tweaking

The per-ticker drift, volatility, and average daily volume live in the
`TICKERS` list at the top of `scripts/gen_mock_data.py`. Edit those and
rerun the script to get a different but still reproducible dataset.
